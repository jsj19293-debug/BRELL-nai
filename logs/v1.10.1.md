# v1.10.1 개발 로그

## 수정

- 씬 프리셋 이름 변경 시 실제 저장 폴더를 새 이름으로 복사·검증한 뒤 이전 폴더를 정리하고, 씬 이미지와 히스토리 경로도 함께 갱신하도록 수정했다. 기존 `nais2-forge-scenes` 구조는 유지하며 파일 충돌이나 검증 실패 시 이름과 원본 경로를 변경하지 않는다.
- 구버전 AppData가 없는 첫 실행에서도 식별자 이전 완료 상태를 기록해, 앱이 현재 데이터 폴더를 생성한 다음 재실행할 때 정상 폴더를 충돌로 오인하던 문제를 수정했다. 기존 현재 데이터는 그대로 보존하고 구버전과 현재 데이터가 실제로 함께 존재하는 충돌 차단은 유지한다.
