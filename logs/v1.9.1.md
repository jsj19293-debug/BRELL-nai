# v1.9.1 개발 로그

## 수정 및 개선

- 프로젝트 문서와 패키지 정보의 이전 제작자·저장소 표기를 현재 Forge 정보로 정리
- 더 이상 사용하지 않는 Discord·Marketplace·Supabase 흔적 제거
- 설정 화면에서 업데이트할 때도 설치 전 자동백업이 누락되지 않도록 업데이트 설치 경로 통일
- 우하단 알림을 더 작고 불투명한 설치 알림 스타일로 개선

### 앱 식별자 및 데이터 경로 변경

- 승인: 2026-08-31 사용자 승인
- 정식 앱 식별자를 `com.iztaciyu.nais2forge`로 변경
- 기존 설치의 Roaming·Local 앱 데이터는 새 WebView가 생성되기 전에 같은 데이터 루트의 임시 경로로 원자적으로 이전하고, 파일 수와 총 크기를 확인한 뒤 새 경로로 전환
- 데이터 전체를 복제하지 않으므로 기존 데이터 용량만큼의 추가 디스크 공간은 필요하지 않음
- 새 경로에 이미 별도 데이터가 있으면 덮어쓰지 않고 중단하며, 중간 종료로 임시 경로에 멈춘 이전은 다음 실행에서 이어서 완료
- 성공 후 기존 식별자 경로는 사라지므로 구버전으로 되돌리려면 새 경로를 기존 식별자 경로로 직접 역이전해야 함
