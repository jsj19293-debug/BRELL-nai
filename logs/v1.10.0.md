# v1.10.0 개발 로그

## 수정

- `#if+`와 `#if-` 조건이 여러 태그를 함께 감싼 강조 블록 내부의 태그도 정확히 인식하도록 수정했다.
- 씬모드에 활성 프리셋의 생성 이미지를 큰 격자창에서 한꺼번에 확인하는 검수 화면을 추가했다.
- 씬 프리셋 선택 도구를 불필요한 인페이지 제목 위치로 통합해 씬 목록의 세로 작업 공간을 넓혔다.
- 프리셋 선택 탭 크기는 유지하면서 펼친 목록의 세로 범위를 늘리고, 각 항목 앞의 전용 손잡이로 드롭다운 안에서 바로 순서를 변경할 수 있게 했다.
- 프리셋 이름 변경·복제·삭제 기능을 선택 드롭다운 옆 설정 버튼으로 묶고, 바깥을 클릭하면 닫히게 했다.
- 우측의 ZIP·Cloudflare·JSON 불러오기·JSON 내보내기 기능을 트리거 중앙에 대칭 정렬한 세로 도구 모음으로 묶고, 바깥을 클릭하면 닫히게 했다.
- 씬 프리셋 선택 폭과 상단 편집·검수·썸네일 도구 규격을 정리해 가로 공간 활용을 개선했다.
- 각 씬 카드 좌상단에 생성 해상도 프리셋 이름을 작게 표시하고 긴 사용자 지정 이름은 말줄임 처리했으며, 상단 버튼으로 표시 여부를 전환할 수 있게 했다.
- 씬 이미지 검수·ZIP 내보내기·Cloudflare 업로드가 각 씬의 최신 즐겨찾기 이미지, 없으면 최신 이미지 한 장을 동일하게 선택하도록 통일했다.
- 씬 이미지 검수창을 전체·개별·미검수·검수완료 탭으로 나누고, 전체보기 위치를 유지한 채 프롬프트·씬 정보·히스토리 3열 개별검수 화면으로 전환할 수 있게 했다.
- 개별검수 화면에 접을 수 있는 프롬프트 편집, 프리셋·참조·캐릭터 선택, 이미지 생성 기능과 현재 검수 대상의 전후 이미지를 보여주는 하단 탐색 막대를 추가했다. 우측 히스토리는 이 화면에서 생성한 이미지만 임시로 표시하며 화면을 닫으면 초기화된다.
- 개별검수 중앙의 중복 씬 프롬프트 제목을 없애고 입력 영역을 넓혔다.
- 개별검수 최초 이미지를 임시 히스토리에 유지해 재생성 후에도 비교할 수 있게 하고, 중앙 이미지와 히스토리 이미지에 재생성·인페인트·참조 추가·메타데이터 불러오기를 포함한 기존 우클릭 퀵액션을 연결했다.
- 검수창에서 실행한 생성 단축키와 프리셋·참조·캐릭터 액션을 검수 화면에서 처리하고, I2I·인페인트 소스 이미지와 설정도 검수창 안에 표시되도록 수정했다.
- 개별검수 히스토리 하단에 통과·탈락 판정 버튼을 추가했다. 판정을 시작하면 통과한 이미지들만 ZIP 내보내기와 Cloudflare 업로드 대상이 되며, 검수하지 않고 바로 출력할 때는 기존 대표 이미지 선택 규칙을 유지한다.
- 별도 개별검수 탭을 없애고 전체보기·미검수·검수완료 목록에서 현재 위치를 유지한 채 상세 검수 화면을 열도록 통일했다. 하단 이미지 큐에는 통과·탈락 상태를 각각 파란색·빨간색 테두리로 표시한다.
- 통과·탈락 판정 후 현재 탭의 다음 이미지로 자동 이동하도록 하고, 미검수·검수완료의 격자와 하단 큐가 같은 필터를 사용하도록 수정했다. 검수완료에는 통과 이미지만 남고 탈락 이미지는 미검수 대상으로 돌아간다.
- 상세 검수 화면에서 씬 프롬프트를 직접 수정할 수 있게 하고, 최종확인 탭에 최종 이미지 수·전체 씬 수·공통 파일명 규칙·ZIP/Cloudflare 출력 방식을 모은 패널을 추가했다.
- 검수 격자에서 이미지가 없거나 로드에 실패한 씬을 붉은 빈 셀로 유지하고, 최종확인 패널에 실제 ZIP·Cloudflare 파일명 규칙으로 계산한 이미지 이름 예시를 최대 3개 표시하도록 개선했다.
- 검수창에서 덧그리기를 실행해도 스마트툴 탭으로 이동하지 않고 현재 검수 화면 위에서 편집하도록 수정했다. 덧그리기 결과는 원본을 교체하지 않고 기본 출력 경로에 새 파일로 바로 저장할 수 있으며, 검수에서 로드 실패로 확인된 이미지는 ZIP·Cloudflare 출력 대상에서 제외된다.
- 최종확인에서 이미지를 개별적으로 출력 대상에서 제외하거나 다시 포함할 수 있게 하고, 최종 수량·이름 예시·ZIP·Cloudflare 출력에 같은 선택을 적용했다.
- 덧그리기를 앱 공통 다이얼로그로 통합해 어느 화면에서 실행해도 스마트툴 탭으로 이동하지 않게 했다. 파일에서 시작한 작업은 원본의 실제 폴더에 저장하며, 씬 이미지 결과는 씬 이름이 아닌 기존 물리 경로를 이어받아 새 이미지로 같은 씬에 등록한다.
