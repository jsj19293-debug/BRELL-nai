# v1.12.0 개발 로그

## 이미지 공유 카드

- 메인 탭 프롬프트 패널의 `조각`·LLM API 버튼 사이에 `이 프리셋의 프롬프트 공유` 버튼을 추가했다. 선택 이미지 없이도 현재 프롬프트와 생성 설정으로 카드를 만들며, 이미지는 카드에 싣지 않는다. 세로형 카드에 모델·모드, 최종 생성 프롬프트, 네거티브, 스텝, CFG, 샘플러, 스케줄러, 품질/UC 프리셋을 정렬한다.
- 카드의 항목명은 연한 로열골드색 굵은 글씨, 값은 밝은 글씨로 표시하며 개별 박스형 컨테이너를 사용하지 않는다. 프롬프트 전문은 길이에 맞춰 카드 높이가 늘어난다.
- 카드 PNG에는 현재 설정을 생성 요청과 같은 프롬프트 처리 경로로 해석한 결과를 공식 NovelAI `Comment`·`Source` 형식과 Forge `nais2-params` 형식으로 함께 기록한다. 원문 프롬프트는 별도로 보존하며, 사용자 저장 데이터나 기존 이미지는 변경하지 않는다.
- 새 기능에 따라 개발 대상 버전은 v1.12.0이다. 실제 앱 버전은 릴리즈 요청 전까지 v1.11.0을 유지한다.
- 카드 화면에서 PNG 다운로드, PNG 클립보드 복사, 독립 HTML 코드 복사를 제공한다. 화면의 각 값 옆 복사 버튼은 그 값만 복사하며, HTML 코드에도 항목별 복사 버튼을 포함한다.

## R2 다이렉트 업로드

- 메인·히스토리·씬·검수에서 사용하는 R2 다이렉트 업로드 목록의 파일 이름을 이미지별로 수정할 수 있다. 확장자는 실제 업로드 포맷에 맞춰 고정하고, 일괄 업로드 내 중복 이름에는 구분 번호를 붙인다. 업로드 직전 R2 경로를 다시 조회해 확인된 기존 파일과 이름이 같으면 업로드를 중단한다.
- 업로드 목록은 기존의 간결한 한 줄 배치를 유지하고 파일명 입력칸과 확장자만 표시한다. 중복된 씬 이름·전체 경로 표시는 제거했다.

## 이미지 내보내기 기본 설정

- 시험용 PNG 최적화 옵션을 제거했다. ZIP 내보내기와 R2 이미지 업로드의 기본 포맷·WebP 품질을 저장 설정에서 선택할 수 있다. 기본값은 PNG·90이며 기존 생성 이미지 저장 포맷 설정과 분리된다.
- ZIP 내보내기와 R2 업로드창에서 바꾼 포맷·품질은 해당 작업에만 적용된다. WebP 품질 슬라이더는 WebP 선택 시에만 보이며, 다른 포맷으로 바꿔도 저장된 기본 품질은 유지된다.
- R2 다이렉트 업로드와 R2 페이지의 로컬 이미지 업로드는 전송 전에 포맷을 선택한다. 파일명 확장자와 전송 MIME은 실제 결과에 맞춘다. PNG를 PNG로 전송하고 EXIF 제거가 꺼져 있으면 원본 바이트를 유지하며, 포맷 변환 시에는 픽셀 재인코딩으로 이미지 내 메타데이터가 사라질 수 있다. 이미지가 아닌 파일은 변환하지 않는다.
- 사용자 승인에 따라 기존 `nais2-forge-settings`에 두 기본 설정 필드만 추가했다. 기존 필드·키·이미지 파일은 보존하고, 이전 설치 데이터는 누락 필드에 기본값을 적용한다. 별도 migration이나 삭제는 없으며 문제 시 이 필드와 UI를 되돌릴 수 있다.
- 이번 변경 사항을 안내하는 1회성 공지 문구를 갱신했다. 새 공지 ID를 사용해 이전 공지 확인 여부와 구분하며, 저장 구조는 변경하지 않는다.
- 공지 문구 위치와 새 공지 게시 시 ID를 함께 변경해야 하는 절차를 회귀 기록에 남겼다.
