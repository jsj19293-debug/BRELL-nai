# NAIS2-Forge v1.9.0 개발 로그

## 주요 변경

### NovelAI 다중 계정 토큰

API 설정에서 NovelAI 토큰 입력칸을 여러 개 추가하고, 각 토큰을 검증해 현재 생성에 사용할 계정으로 전환할 수 있도록 추가.

- 마지막으로 검증에 성공한 토큰이 현재 활성 토큰이 되며, 계정 전환과 자동 순환은 헤더의 계정 메뉴에서 관리한다.
- 승인: 2026-08-30 사용자 승인.
- 저장 변경: 기존 `nais2-forge-auth`의 단일 활성 `token`은 그대로 유지하고, 검증된 추가 토큰 목록인 선택적 `tokens` 필드만 더한다. 저장 키와 기존 토큰 값은 변경하거나 이동하지 않는다.
- 호환성/복원: 이전 설치에서 목록 필드가 없으면 기존 단일 토큰을 첫 입력칸으로 그대로 사용한다. 별도 migration이나 기존 데이터 재작성은 없으며, 이전 코드로 되돌려도 기존 `token` 필드를 계속 읽을 수 있다.

### 헤더 계정 전환

상단 탭 왼쪽의 계정 메뉴에서 등록된 토큰별 Anlas와 V5 할당량을 확인하고, 계정 항목을 눌러 활성 계정을 전환할 수 있도록 추가.

- 계정 이름은 전체 토큰을 노출하지 않고 토큰 앞부분만 표시한다.
- 잔액과 할당량은 메뉴를 열 때 조회하며 별도로 저장하지 않는다.

### 계정 자동 순환

헤더의 계정 설정에서 등록된 계정을 순서대로 사용하고, 계정당 성공 이미지 수와 생성 불가 계정 건너뛰기를 설정할 수 있도록 추가.

- 직접 한 장 생성, 반복 생성, 씬 큐, 메인 및 히스토리 재생성을 포함한 모든 이미지 생성 경로가 같은 성공 이미지 수를 사용한다. 실패한 요청은 장수에 포함하지 않는다.
- 계정당 이미지 수는 증감 버튼 없이 숫자만 직접 입력한다.
- V5 할당량 표시는 반올림된 참고값으로만 사용한다. 실제 생성 요청이 HTTP 402를 반환해 V5 사용 한도와 Anlas 모두로 해당 요청을 처리할 수 없음이 확인된 경우에만 다음 계정으로 넘긴다.
- 등록 계정이 하나뿐이거나 모든 계정이 같은 이유로 생성 불가하면 마지막 API 오류를 기존 생성 실패 경로에 그대로 전달한다. 네트워크·서버·요청 제한 오류는 중복 생성을 피하기 위해 자동 재시도하지 않는다.
- 승인: 2026-08-30 사용자 승인.
- 저장 변경: 기존 `nais2-forge-auth` 키에 `accountRotationEnabled`, `accountRotationImages`, `accountRotationSkipDepleted` 설정만 선택적으로 추가한다. 기본값은 순환 끔, 계정당 1장, 생성 불가 계정 건너뛰기 켬이다.
- 호환성/복원: 기존 `token`과 `tokens` 값 및 저장 구조는 변경하지 않는다. 생성 장수는 실행 중에만 세어 이미지마다 영속 저장하지 않으며, 이전 버전은 추가 설정을 무시하고 기존 활성 토큰을 그대로 사용한다.
