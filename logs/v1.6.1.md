# v1.6.1 Development Log

## 수정 및 개선

- 히스토리 이미지 복사가 표시용 썸네일 캐시 상태와 무관하게 원본 이미지를 클립보드에 복사하도록 수정하고, 성공·실패 결과를 안내하도록 개선했다.
- 인페인트, 덧그리기, 모자이크 편집기에 제한된 실행 취소·다시 실행 이력과 `Ctrl+Z`, `Ctrl+Shift+Z`, `Ctrl+Y` 단축키를 추가했다. 새 편집 후 Redo 분기는 폐기되며 초기화 작업도 되돌릴 수 있다.
- 프롬프트 편집기의 실행 취소·다시 실행이 자동완성 입력창의 실제 편집 작업과 일치하도록 수정했다. 짧은 연속 입력만 한 작업으로 묶고, 공백·쉼표·개행·커서 이동·붙여넣기·자동완성·가중치 조절·한글 조합은 명확한 작업 경계로 기록하며 이력은 최대 100단계로 제한한다.
- 씬 프롬프트 입력은 기존 지연 저장으로 타이핑 성능을 유지하면서, 생성 버튼·공통 생성 버튼·생성 단축키로 세션을 시작하는 순간 positive와 negative의 최신 로컬 초안을 먼저 반영하도록 수정했다.

## 데이터 호환성

### 모델별 생성 파라미터 기억

- 승인: 2026-08-25 사용자 승인 후 진행.
- V5와 V4.5 등 모델을 전환할 때 Steps, Prompt Guidance, Rescale, Sampler, Scheduler, 해상도, UC Preset, Quality Tags, Mode, 투명 배경, Variety, SMEA가 다른 모델로 이어지지 않고 각 모델의 마지막 값을 복원하도록 변경했다.
- 기존 `nais2-forge-generation` 키와 활성 모델의 기존 필드는 유지하고, 비활성 모델 값은 additive `modelOptionMemory`에 저장한다. 새 구조를 처음 읽을 때 현재 값을 모든 모델의 초기값으로 복제하며, 이후 각 모델에서 변경한 값과 기존에 저장된 모델별 선택은 그대로 보존한다.
- 기존 생성 프리셋과 메타데이터 임포트는 기존 generation store 액션을 통해 대상 모델 값만 갱신한다. 이전 버전으로 롤백하면 새 필드는 무시되며 기존 필드는 유지된다.
