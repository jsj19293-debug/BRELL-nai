# v1.9.3 개발 로그

## 수정

- 제작자명 변경 이전에 사용하던 설치 위치를 업데이트 설치기가 다시 인식하도록 수정했다. 기존 위치에 실제 실행파일이 있을 때만 해당 경로를 이어받고, 설치 완료 후 현재 제작자 키에도 같은 경로가 기록되어 이후 업데이트가 연속적으로 적용된다.
- 이번 변경은 설치 실행파일 위치만 바로잡으며 앱 데이터 경로, 저장 구조, 사용자 프롬프트·프리셋·이미지는 변경하지 않는다.
- 잘못 생성된 Local Programs 설치본은 자동 삭제하지 않아, 기존 설치 경로의 새 버전 동작을 확인하기 전에도 복구 경로를 보존한다.
