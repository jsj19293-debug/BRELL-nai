# v1.9.2 개발 로그

## 수정 및 개선

### 앱 식별자 데이터 이전 복구

- 승인: 2026-08-31 사용자 승인
- v1.9.1 첫 실행에서 HTTP 플러그인이 새 Local 데이터 경로에 빈 `.cookies`를 먼저 생성해 기존 데이터 이전이 충돌로 중단되던 문제 수정
- 새 경로를 사용하는 HTTP 플러그인은 기존 Roaming·Local 데이터 이전이 완료된 뒤 초기화
- 이미 실패한 실행이 남긴 새 경로는 정확히 0바이트 `.cookies` 하나만 있을 때만 초기화 흔적으로 제거하고 이전을 재개
- 그 외 파일이나 내용이 있는 `.cookies`가 존재하면 기존처럼 이전을 중단해 사용자 데이터를 덮어쓰지 않음
- 기존 데이터는 계속 같은 데이터 루트에서 원자적으로 이동하며, 중간 실패 시 임시 경로에서 다음 실행에 복구
